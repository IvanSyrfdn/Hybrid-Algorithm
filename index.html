01 / Konteks Permasalahan

Tantangan Penjadwalan DAG Workflow di Cloud Heterogen

Kompleksitas NP-Hard pada DAG Scheduling

Aplikasi scientific workflow dimodelkan sebagai Directed Acyclic Graph (DAG) yang memiliki ketergantungan antar-tugas (data dependencies). Memetakan tugas-tugas ini ke VM heterogen untuk meminimalkan makespan merupakan masalah optimasi NP-Hard.

PENDEKATAN TUNGGAL A Heuristik Murni

Cepat, Namun Terjebak Local Optima

  • • Contoh: HEFT, Min-Min, Max-Min.
  • • Eksekusi deterministik dalam hitungan milidetik.
  • • Bersifat greedy lokal; kurang adaptif saat skala graf tugas sangat kompleks.
PENDEKATAN TUNGGAL B Metaheuristik Murni

Pencarian Global, Namun Lambat

  • • Contoh: PSO Standar, GA, ACO.
  • • Populasi awal dibangkitkan secara acak.
  • • Konvergensi lambat & sering memicu communication overhead antar-VM.
SOLUSI HYBRID

Menggabungkan kecerdasan Heuristik sebagai titik awal (smart seeding) bagi eksplorasi global Metaheuristik.

02 / Kandidat Evaluasi

Dua Kandidat Algoritma Hybrid yang Dibandingkan

OPSI TERPILIH
Heuristik × Metaheuristik

PEFT-PSO

Predict Earliest Finish Time + Particle Swarm Optimization

1. Fase Heuristik (Look-Ahead OCT)

Menghitung Optimistic Cost Table (OCT) secara bottom-up dari exit node ke entry node untuk memprediksi sisa waktu eksekusi tercepat sebelum pemetaan dilakukan.

2. Fase Metaheuristik (PSO Seeding)

Jadwal berkualitas tinggi dari PEFT langsung disuntikkan sebagai Global Best awal (G_best) pada kawanan partikel PSO untuk menyempurnakan pemetaan Task-to-VM.

Fokus Utama: Minimum Makespan & Konvergensi Cepat
Kandidat Pembanding
Memetic Algorithm (Evolusioner × Local Search)

MA-NSGA-II

Memetic Algorithm berbasis NSGA-II + Critical-Path Local Search

1. Pencarian Global Multi-Objektif (NSGA-II)

Mengeksplorasi himpunan solusi Pareto-optimal menggunakan fast non-dominated sorting dan crowding distance untuk menyeimbangkan waktu, biaya sewa VM, dan konsumsi daya.

2. Intensifikasi Lokal (Neighborhood Search)

Pada setiap generasi, individu terbaik diasah melalui operator task-swapping dan VM-reassignment di sepanjang jalur kritis (critical path) DAG.

Fokus Utama: Trade-Off Pareto (Waktu vs. Biaya/Energi)
03 / Justifikasi Keputusan

5 Aspek Mengapa PEFT-PSO Dipilih Sebagai Opsi Terbaik

01

Makespan Absolut (Unggul 10–20%)

Fokus murni menekan total waktu eksekusi ke batas minimum tanpa mengorbankan kecepatan demi trade-off biaya/energi.

★ Kinerja Waktu Tertinggi
02

Kecepatan Konvergensi

Smart seeding dari PEFT menempatkan partikel PSO dekat dengan titik optimal global sejak iterasi ke-0.

★ Minim Iterasi Terbuang
03

Kemampuan Look-Ahead (OCT)

Memprediksi biaya eksekusi hingga exit node, mencegah jebakan greedy yang memicu penalti transfer data antar-VM.

★ Anti-Bottleneck DAG
04

Kompleksitas Waktu Rendah

Pra-pemrosesan OCT hanya O(v²·p), jauh lebih ringan dibanding siklus non-dominated sorting + local search MA-NSGA-II.

★ CPU Overhead Ringan
05

Kesesuaian SLA & Real-Time

Ideal untuk aplikasi berbatas waktu ketat (Montage, CyberShake). MA-NSGA-II lebih cocok untuk skenario Green Cloud.

★ Presisi Deadline SLA

04 / Cara Kerja Algoritma

Arsitektur Dua Fase pada Hybrid PEFT-PSO

FASE 1A // BOTTOM-UP

Hitung Matriks OCT

Menelusuri DAG dari exit task ke entry task untuk menghitung estimasi waktu eksekusi minimum tersisa pada setiap VM.

FASE 1B // LOOK-AHEAD

Pemetaan O_EFT

Mengurutkan prioritas tugas berdasarkan rank_OCT, lalu memilih VM dengan nilai EFT + OCT terkecil.

FASE 2A // SEEDING

Injeksi G_best Awal

Solusi jadwal PEFT dikodekan menjadi partikel pertama dan dijadikan panduan global awal (G_best) kawanan PSO.

FASE 2B // REFINEMENT

Eksplorasi Swarm PSO

Partikel memperbarui kecepatan dan posisi untuk mencari kombinasi Task-to-VM yang lebih optimal di sekitar titik awal.

Persamaan 1: Optimistic Cost Table (OCT)

Fase Heuristik
OCT(Tᵢ, VMₖ) = maxTⱼ ∈ succ(Tᵢ) { minVMw [ OCT(Tⱼ, VMw) + w(Tⱼ, VMw) + c̄ᵢⱼ ] }
O_EFT(Tᵢ, VMₖ) = EFT(Tᵢ, VMₖ) + OCT(Tᵢ, VMₖ)

Keterangan: w(Tⱼ, VMw) = waktu eksekusi tugas anak, c̄ᵢⱼ = biaya transfer data (0 jika pada VM yang sama).

Persamaan 2: Pembaruan Partikel PSO

Fase Metaheuristik
vᵢ(t+1) = ω·vᵢ(t) + c₁r₁(P_best,i − xᵢ(t)) + c₂r₂(G_best − xᵢ(t))
xᵢ(t+1) = round( xᵢ(t) + vᵢ(t+1) ) → Indeks VM Target

Keterangan: G_best diinisialisasi langsung dari hasil pemetaan PEFT sehingga konvergensi berlangsung sangat cepat.

07 / Penutup & Rekomendasi

Kesimpulan Akhir & Panduan Pemilihan Strategi

KESIMPULAN 01

Sinergi Look-Ahead & Swarm

Kombinasi PEFT-PSO mengatasi kelemahan inisialisasi acak pada PSO standar melalui matriks Optimistic Cost Table (OCT), menghasilkan jadwal awal yang sudah dekat dengan titik optimal global.

KESIMPULAN 02

Reduksi Makespan Signifikan

Terbukti memangkas makespan hingga 38,8% dibanding PSO standar pada simulasi mikro dan unggul 10–20% dibanding MA-NSGA-II pada skenario workflow skala besar.

KESIMPULAN 03

Efisiensi Komputasi Broker

Dengan kompleksitas pra-pemrosesan O(v²·p), PEFT-PSO sangat ringan dan andal untuk diimplementasikan pada Cloud Resource Broker berbatas waktu ketat.

Gunakan PEFT-PSO (Rekomendasi Utama) Jika:

  • Prioritas utama sistem adalah minimum makespan dan strict SLA deadline.
  • Menangani scientific workflow kompleks dengan ketergantungan data tinggi.
  • Membutuhkan waktu pengambilan keputusan penjadwalan yang cepat dan ringan.

Gunakan MA-NSGA-II (Future Work) Jika:

  • Sistem menuntut optimasi multi-objektif (kompromi waktu vs. biaya & energi).
  • Diterapkan pada skenario Green Cloud Computing untuk menekan emisi karbon.
  • Toleransi terhadap waktu komputasi penjadwalan yang lebih lama dapat diterima.
